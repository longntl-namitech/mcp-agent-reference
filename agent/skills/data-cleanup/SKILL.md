# Data cleanup

Use this when the user wants cleaner contact and company records.

1. Search for tools that list contacts without a company and that find contacts by email or name.
2. Group likely duplicates by matching email, phone or name. State why each group matches.
3. List contacts that have no company and suggest a company when the email domain makes it obvious.
4. Present the plan first: which records to merge, which to link. Do not change anything until the user agrees.
5. Apply each approved fix with the merge or update tools. Each write pauses for approval, so do them one at a time and report the outcome of each.
