# Follow-up planning

Use this when the user asks what to do next or who needs a nudge.

1. Search for tools that list open deals, open tasks and overdue tasks.
2. Rank open deals by value and by how long they have had no task or note.
3. For each of the top deals, check its tasks and recent notes so you do not repeat work.
4. Propose at most five follow-ups. Give each a title, a due date and the reason.
5. Create a task only after the user picks it. Task creation pauses for approval.
